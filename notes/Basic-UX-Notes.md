Basic UX for Programmers Notes
===

Talk by Hilary Tohs-Krause ([yt](https://www.youtube.com/watch?v=Jf0cjocP8Wk))

* 60-100 characters per line (10-20 words per line?)
  - 50-60 preferred
  - `ch` unit (length of `0` (0x30) character)
* Line height 1.4
  - New York Times has 1.4
* `15px` padding
* Have contrast for you text
  - Don't put yellow over white background
  - [Contrast Checker](https://webaim.org/resources/contrastchecker/) (([example](https://github.com/Pushedskydiver/Colour-Contrast-Checker) [demo](https://colourcontrast.cc/?))
* `16px` or `18px` text size (`16px` default size)
* Highlight key content
* we read better with mixed upper and lower case
* use lists
* first two words rule:
  - first two words in a sentence have outsized impact
* Limit text decoration
  - 2 or 3 different typefaces
  - limit colors to 2-3, not including shading
* Basic font for main text, more complex font for headers
* icons are misinterpreted, so prefer text description labels
  - work best in navigation
* integrate images with content
  - don't use banners
  - make sure it's relevant or informative
* alternate between small, medium and wide
* progessive disclosure
* 'F' shape reading pattern
* top to bottom importance ordering
* put important information above the fold
* avoid putting important content in ad areas
* Be consistent with links and buttons
  - links should be formatted the same (color, underlines, etc.)
  - buttons should have the same formatting around them (boxes, colors, etc.)
* Misc
  - 3,2,1 column format
  - avoid caroselles
