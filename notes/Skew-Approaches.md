* Invert the problem

* How does it behave in the large system limit?
* Start from end end and work backwards

* Profile

* Restate assumptions
* Verify assumptions
* Enumerate special cases
* Do the simple thing first
* Kill your darlings
* Break for personal maintenance (eat, sleep, shower, etc.)
* What would your mentor tell you to do?
* Don't be ashamed of using a library
* What old assumptions are challenged by new information?
* Abstract common tasks
* Don't prematurely optimize
* Make it into a single function
* Don't be afraid to cut-and-paste code
* Comment code
* Visualize output
* Verify input data
* Verify output solution
* Use print statements to debug
* Log operations
* Visualize the algorithm as it's running
* Make variable and/or function names more descriptive

* Is it NP-Complete?
* Is there an ensemble that makes it polynomial time solvable?

* Does it need to be done more than once?

* Add a term that will then go to 0
* Can it be conditioned to be naively parallelizable?
* Does the dependence still hold at large scales?
