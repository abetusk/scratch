Game Ideas
---

Ideas are a dime a dozen. Implementation is what counts.

Feel free to use them without credit!

---

* Pac-man like game like vampire survivors 
  - infinite grid with ghosts that chase you
  - eating pellets gives you fruit power ups
    + different fruit give you different power ups
    + maybe 2-3 different fruits are available, with the
      the others disappearing once you make a choice
  - super pellets give temporary immunity
* Overcooked + crypt of the necrodancer
  - players in kitchen need to move on the beat
  - moves consist of physical moves or chopping, combining, etc
    + maybe only mechanic is move, like necrodancer, but bumping into things
      activates? (bump into tomato bin to grab tomato, bump into chopping station
      to drop, bump again to chop, bump again to pick up)
  - music needs to have a definite beat (([example](https://freemusicarchive.org/music/sawsquarenoise/RottenMage_SpaceJacked))
  - have a preliminary area before level starts to get player acclimated to beat
    + serves as a sanity test to make sure the player can do the beat matching
  - need to experiment but chopping should probably be pretty quick, so the
    goal is to get as many items out within the time frame
  - added bonus: multiplayer can have spectators that can order as they watch
  - this is not so casual as the beat matching requires concentration
  - kaykit has some decent assets for this ([here](https://kaylousberg.itch.io/restaurant-bits))
* killer queen clone
  - use top-down zelda-like assets ([example](https://pixel-boy.itch.io/ninja-adventure-asset-pack))
  - even 1-bit asset packs will work with enough juice
